fix: the plugin reports its real version

The `// @generated by protoc-gen-connectum-catalog v…` header of `catalog.gen.ts` and the version `buf` shows for the plugin came from a hard-coded literal (`1.0.0-rc.11`) that no release ever updated. The version is now read from the package's own `package.json`, so it always equals the installed version. A committed `catalog.gen.ts` gets a one-line header diff on each plugin upgrade, as with other generators.
