feat: `protoc-gen-connectum-catalog` refuses a repeated `output_file` option and puts the `@generated` marker first. `opt: [output_file=a.ts, output_file=b.ts]` used to write only `b.ts` with no message; it now fails with `output_file given more than once ("a.ts", "b.ts")` and writes nothing. The `// @generated by protoc-gen-connectum-catalog vX.Y.Z. DO NOT EDIT.` line was printed below the import block, where tools that skip generated files do not look for it; it is now the first line of `catalog.gen.ts`. Give `output_file` once; regenerate to get the moved marker (nothing else in the file changes).
